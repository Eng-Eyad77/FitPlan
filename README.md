# FitPlan

A workout planning and tracking app for iPhone and Android, in Arabic and English. Plan your workouts, log every set, rest between sets, and track your progress.

## Repository

| Folder | What it holds |
| --- | --- |
| `Backend/FitPlan.Api` | ASP.NET Core API |
| `Backend/FitPlan.Migrator` | Database migrations and data tools |
| `Frontend/fitplan_app` | Flutter mobile app |
| `Frontend/fitplan_admin` | Flutter Web admin dashboard |
| `Frontend/fitplan_shared` | Theme and widgets shared by both Flutter apps |
